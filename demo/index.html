What it does

Capture → Understand → Assist

Capture

A small Windows agent hooks the mouse globally and records every click, on both monitors, into a local database that builds up across sessions.

Understand

Clicks land in grid zones over the virtual desktop. The dashboard shows the hot zones, session history and trends, and exports a PDF report.

Assist

A transparent overlay glows where you click. A quick double-click sends the pointer back to your busiest spot, so you don't have to drag across two screens.

Architecture

Two runtimes, one local file

A browser can only see clicks inside its own window, so capture runs natively on Windows. Everything else is an ordinary web service. They share a single SQLite file.

Presenter run sheet

A five-minute walkthrough

  1. Story (1 min). Scroll through What it is, How it works and Privacy on this page.
  2. History (30 s). In Live demo, point out last week's sample sessions, the trend, and the busy ribbon zone (top-left).
  3. Live capture (2 min). Switch to Word and work through the task list in Mouse-AI-Practice.docx. Orange glows follow each click. Switch back here: This session has grown and the zones have lit up.
  4. Assist (30 s). Move the pointer to the far corner of the other monitor and quickly double-click. The pointer jumps back to the area you've been clicking most.
  5. Report (30 s). Click PDF on the current session row. The report shows aggregated totals only.
  6. Wrap. Press Esc to hide the overlay. Run Stop-Demo to close everything.
